Design System

Cursor Brand & Visual Language

Calm, technical, credible, quietly premium. Full light/dark theme support included. Use this file as the source of truth when building Cursor-branded interfaces.

Foundation

Design Philosophy

Four principles that govern every visual decision in both light and dark modes.

01
Whitespace is load-bearing

It communicates confidence. Do not fill empty space. If a section feels crowded, remove elements.

02
Data beats decoration

Screenshots and data cards beat illustrations every time. Content proves value — don't dress it up.

03
Grayscale carries 90%

Orange is punctuation, not a theme. Use it once per view. Never on headlines, body, or large fills.

Default mode is Cursor Light — warm off-white canvas, editorial headlines, hairline borders, rounded cards. Dark mode maps every token to a matching dark equivalent. The toggle above updates all live demos on this page.

Official brand rules (Air.inc brand PDF, June 2026)
Orange is accent only

Never a large fill, button background, or header band. One usage per view: small intentional highlights and data emphasis only.

No green, no red

All positive indicators use orange tint or neutral gray. All negative indicators use neutral gray. The words "green = savings" and "red = risk" are brand violations.

Logo: rounded-corner cube only

Use the current cube (rounded corners). The old sharp-corner cube is prohibited. No custom lockups. Minimum clear space = 1/3 of cube width on all sides. Dark cube on light backgrounds, white cube on dark.

Orange: #E8601B (brand PDF) / #f54e00 (live deck)

The official brand PDF cites approximately #E8601B; confirmed live-deck value is #f54e00. Both are used across Cursor assets.

Part 2 — JavaScript: toggle + localStorage + system preference
/**
 * Cursor theme toggle
 * - Respects prefers-color-scheme on first visit
 * - Persists user choice to localStorage
 * - Sets data-theme="light" | "dark" on <html>
 */

const STORAGE_KEY = 'cursor-theme';

function getPreferredTheme() {
  const saved = localStorage.getItem(STORAGE_KEY);
  if (saved) return saved;
  return window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light';
}

function applyTheme(theme) {
  document.documentElement.setAttribute('data-theme', theme);
  localStorage.setItem(STORAGE_KEY, theme);
}

function toggleTheme() {
  const current = document.documentElement.getAttribute('data-theme') || 'light';
  applyTheme(current === 'dark' ? 'light' : 'dark');
}

// Apply on page load — BEFORE first paint to avoid flash
applyTheme(getPreferredTheme());

// React to OS-level changes (if user hasn't manually chosen)
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', e => {
  if (!localStorage.getItem(STORAGE_KEY)) {
    applyTheme(e.matches ? 'dark' : 'light');
  }
});

// HTML: wire up your toggle button
// <button onclick="toggleTheme()">Toggle theme</button>
Part 3 — Framework patterns
React hook
function useTheme() {
  const [theme, setTheme] =
    useState(getPreferredTheme);

  useEffect(() => {
    document.documentElement
      .setAttribute('data-theme', theme);
    localStorage.setItem(
      'cursor-theme', theme);
  }, [theme]);

  const toggle = () =>
    setTheme(t =>
      t === 'dark' ? 'light' : 'dark');

  return { theme, toggle };
}

// composables/useTheme.js
export function useTheme() {
  const theme = ref(
    localStorage.getItem('cursor-theme')
    ?? (window.matchMedia(
      '(prefers-color-scheme: dark)')
      .matches ? 'dark' : 'light')
  );

  watch(theme, val => {
    document.documentElement
      .setAttribute('data-theme', val);
    localStorage.setItem(
      'cursor-theme', val);
  }, { immediate: true });

  const toggle = () =>
    theme.value =
      theme.value === 'dark'
        ? 'light' : 'dark';

  return { theme, toggle };
}
Dark mode rules
RuleDetail
Always use CSS variablesNever hardcode hex values in components — they won't switch with the theme. color: var(--text-primary) not color: #1a1a1a.
Avoid inline style hex valuesIn React/Vue/HTML, hardcoded inline hex breaks theme switching. Prefer CSS classes with variable references, or use CSS-in-JS with the variable names.
Don't invert imagesProduct screenshots and logos generally don't need a dark-mode variant. Use the white Cursor logo on dark-background hero sections, dark logo on light sections — this is a placement rule, not a theme rule.
Charts stay fixedThe chart palette (#F76D18, #2C9F28, etc.) is intentionally the same in both modes. These colors are calibrated for legibility on either canvas.
Orange stays orange--accent: #f54e00 is identical in light and dark. It's bright enough to work on dark backgrounds without adjustment.
Code blocks are always darkpre blocks use a fixed dark background (#141416) regardless of theme — dark code blocks are the universal convention.
No flash on loadApply the theme to <html> before first paint — put the applyTheme() call in a <script> tag in <head>, not in a deferred bundle.
Typography

Type Scale & Rules

Headlines use normal (not bold) weight. Bold is reserved for a single-word emphasis or standalone stat. Never center body text.

Font Stacks
Display — headlines, large UI text, stat numbers
Cursor Gothic → Helvetica Neue → -apple-system
Body — UI copy, labels, metadata, paragraphs
-apple-system → Inter → Helvetica Neue → Arial
Mono — code, terminal, numeric table cells (NOT stat numbers)
JetBrains Mono → Courier New → monospace

Google Slides / Docs fallback: Helvetica (not Helvetica Neue). Prohibited fonts: Calibri, Sora, Times New Roman, Cambria. Official brand source: Cursor Brand System & Guidelines PDF (Air.inc, June 2026).

Quality

Pre-Delivery Checklist

Dark Mode
  • No hardcoded hex in components — all var(--token)
  • Toggle tested in both modes
  • No flash on page load (script in head)
  • OS preference respected on first visit
  • Status badges readable in dark mode
  • Code blocks stay dark in both modes
Visual
  • Text contrast passes AA in both modes
  • Orange NOT on body text or large fills
  • Max one orange element per section
  • No box-shadow on cards
  • No gradient fills
  • Every section breathes — 16px min gap
Structure & Copy
  • Self-contained HTML (no CDN calls)
  • Max 2 font weights per view
  • Display font for stat numbers (not mono)
  • Structural eyebrows use var(--text-muted)
  • Headlines lead with the takeaway
  • No "AI-powered", "seamless", "robust"
